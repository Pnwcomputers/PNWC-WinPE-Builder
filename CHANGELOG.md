# Changelog

## 0.1.0-alpha.1 - 2026-11-23

- Initial public source release derived from the supplied PNWC WinPE build script.
- Added setup instructions, input examples, upstream inventory, licensing boundaries, contribution/security policies, and automated source checks.
- Added explicit disk-write safeguards, managed build-directory checks, HTTPS-only downloads, and opt-in execution of third-party preparation tools.
- Removed automatic PassMark host installation/uninstallation and stress/benchmark workflows from the WinPE project.
- Removed automatic Sysinternals EULA acceptance and arbitrary-drive log destination discovery.
- Linked the deployment/recovery workflow to the Ultimate Cybersecurity Master Guide.

This release has not completed full ADK, VM boot, physical USB/VHD, or per-tool compatibility testing. Source checks do not establish operational readiness.
